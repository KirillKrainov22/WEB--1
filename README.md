# Лабораторные работы по веб-программированию

Командный сайт со страницами участников.

- **Лабораторная №1:** HTML, CSS и JavaScript; личные страницы, тема и интерактивные элементы.
- **Лабораторная №2:** Vite и загрузка проектов из публичного API.
- **Лабораторная №3:** главная страница и страница Любови перенесены на React и TypeScript с CSS Modules. Содержание и функции сохранены. Остальные участники переносят свои страницы отдельно.

**Опубликованный сайт:** https://kirillkrainov22.github.io/WEB--1/ (локальные изменения появятся после согласования и публикации).

## Главная страница

Нужны Node.js 22.12+ и npm. Команды выполняются в корне репозитория:

```sh
npm ci
npm run dev
npm run build
npm run preview
```

`src/App.tsx` содержит компоненты главной страницы: Hero с Lottie-анимацией, Team, Footer и интерфейс раскрытия контактов. Тема хранится в состоянии React и сохраняется через `src/useTheme.ts`. Lottie устанавливается как зависимость, а экземпляр анимации удаляется при очистке эффекта.

`src/App.module.css` содержит локальные классы, `src/global.css` — сброс, шрифты и переменные темы. `npm run build` сначала проверяет типы, затем собирает страницу в `dist/`.

## Личные страницы

Страницы находятся в `members/<имя>/`. Для страницы Любови:

```sh
cd members/lyuba
npm ci
npm run dev
npm run build
npm run preview
```

Каждая страница с `package.json` собирается отдельно. Страницы без него публикуются как статические файлы. Подробности реализации — в личных README.

## Общая публикация

GitHub Actions устанавливает зависимости и собирает главную страницу в корне, затем отдельно собирает личные страницы. Содержимое сборок объединяется в `_site/`: главная в корне, личные страницы в `members/<имя>/`. Общие изображения сохраняются для совместимости с существующими страницами.

Ссылки между главной и личными страницами проверяются на собранном общем сайте: отдельный Vite-сервер участника не обслуживает главную. `node_modules/`, `dist/` и `_site/` не включаются в Git.

Публикация запускается при отправке в `main` или вручную через Actions. До согласования изменения остаются локальными.
