Сайт группы для домашнего задания 1: главная страница о команде
и отдельная страница о каждом участнике.

## Структура

```
index.html          — главная: о нас, участники, контакты
members/
  member-1.html     — страница участника 1
  member-2.html     — …
  member-3.html
  member-4.html
styles.css          — общие стили для всех страниц
app.js              — общий JavaScript для всех страниц
animation.json      — Lottie-анимация на главной
images/             — фото участников (сейчас там только заглушка avatar.svg)
```

## Кто что правит

| Файл | Кто |
|---|---|
| `index.html` | один ответственный за главную |
| `members/<имя>.html` | каждый — только свою страницу |
| `styles.css`, `app.js` | один ответственный; остальные просят его или договариваются в чате |

Так никто не перезапишет чужую работу при загрузке файлов на GitHub.

## Что заменить в заготовке

1. **Контакты.** В разделе «Контакты» в `index.html` у каждого своя карточка:
   имя, GitHub (`github.com/login1` → ваш логин, в `href` и в тексте)
   и почта (`name1@example.com` → ваша почта, в `mailto:` и в тексте).
2. **Страницы участников.** Каждый переименовывает свой файл в своё имя
   латиницей: `members/member-1.html` → `members/ivan.html`.
   Затем в `index.html` меняет ссылку в своей карточке на `members/ivan.html`.
   Если вас трое — удалите `member-4.html` и четвёртую карточку на главной.
3. **Фото на своей странице.** Каждый сам выбирает картинку для своей страницы:
   кладёт её в `images/` с именем латиницей в нижнем регистре (`images/ivan.jpg`)
   и меняет `src` у `profile__photo` на `../images/ivan.jpg`
   (`../` — выйти из папки `members`).
   Не забудьте поправить `alt`. Когда у всех будут свои фото, `avatar.svg` можно удалить.
   На главной фото нет: там анимация, а в карточках участников — номера.
4. **Тексты:** описание на главной, увлечения, любимые фильмы, музыка и игры.

## Кнопки на сайте

| Кнопка | Где | Что делает |
|---|---|---|
| Тёмная тема | все страницы | Переключает тему; выбор запоминается и действует на всех страницах |
| Показать контакты | главная | Раскрывает скрытый раздел «Контакты» и прокручивает к нему |
| Подробнее | страницы участников | Показывает и скрывает текст «о себе» |

Пункт меню «Контакты» на главной работает так же, как кнопка «Показать контакты».

Кнопка «Подробнее» находит текст по `id`, поэтому на странице она одна:

```html
<button class="button" id="more-button" type="button">Подробнее</button>
<p class="more" id="more-text" hidden>Скрытый текст</p>
```

## Оформление

Монохромный «журнальный» стиль: чёрный, белый и светло-серый,
заголовки капсом, прямые углы, тонкие линии.

- Все цвета, размеры шрифтов и отступы — переменные в начале `styles.css` (`:root`).
  Чтобы поменять гамму, правьте только их.
- Тёмная тема — те же переменные в `.dark-theme`, только наоборот.
- Шрифт Montserrat подключается из Google Fonts первой строкой `styles.css`.
- Фото лучше подбирать в той же гамме: чёрно-белые или приглушённые.

## Анимация на главной

Анимация «Wavey Birdie» (автор Brian Karungani) с LottieFiles:
https://lottiefiles.com/free-animation/wavey-birdie-DfyxJwguVt —
бесплатная, по лицензии Lottie Simple License.

- библиотека `lottie-web` подключается в `<head>` у `index.html` с CDN;
- сама анимация — файл `animation.json`;
- `app.js` загружает её в блок `#hero-animation` (`lottie.loadAnimation`).

Цвета у анимации свои, в тёмной теме они не меняются.

**Как поставить другую анимацию.** Найдите её на lottiefiles.com, скачайте
в формате «Lottie JSON» и сохраните поверх `animation.json`.

## Как посмотреть локально

Откройте в VS Code папку, где лежит `index.html`, поставьте расширение
**Live Server** и нажмите «Go Live» — сайт откроется по адресу вида
`http://127.0.0.1:5500`.
Если открыть `index.html` двойным кликом, анимация не загрузится:
браузер не даёт скрипту читать `animation.json` с диска.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий (у нас — `WEB--1`).
2. **Add file → Upload files** — перетащите все файлы (включая `animation.json`)
   и папки `images`, `members`.
   `index.html` должен лежать в корне репозитория.
3. **Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`, **Save**.
4. Через минуту-две нажмите **Visit site**.

Перед сдачей проверьте сайт по ссылке: страницы открываются, картинки и анимация загружаются, в Console нет ошибок.
