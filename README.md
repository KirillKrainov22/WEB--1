## Что нужно сделать каждому

### 1. Фото → папка `images/`

- Загрузите своё фото или любую картинку в папку `images/`.
- Имя файла — латиницей, маленькими буквами, без пробелов: `ivan.jpg`.

На своей странице замените путь и подпись:

```html
<img class="profile__photo" src="../images/avatar.svg" alt="Фото: Имя Фамилия" />
```

```html
<img class="profile__photo" src="../images/ivan.jpg" alt="Фото: Иван Иванов" />
```

`../` значит «выйти из папки `members`». Регистр букв важен: `Ivan.JPG` и `ivan.jpg` для GitHub Pages — разные файлы.

### 2. Своя страница → `members/member-N.html`

Файл **не переименовывайте**, на него уже ведёт ссылка с главной. Заполните:

- `<title>` и заголовок `profile__name` — ваше имя;
- `profile__text` — пара предложений о себе;
- `more-text` — текст, который открывается по кнопке «Подробнее»;
- «Мои увлечения» — ярлычки `<span class="tags__item">…</span>`, можно добавлять и удалять;
- «Любимое» — фильм, музыка, игра (`favorite__title` и `favorite__text`);
- «Где меня найти» — ваши ссылки вместо `https://github.com/` и `https://t.me/`.

### 3. Главная → `index.html`

**Раздел «Участники»** — в карточке с вашим номером:

```html
<h3 class="member__name">Имя Фамилия</h3>
```

**Раздел «Контакты»** — в карточке с вашим номером. Ссылку и почту меняйте в двух местах: в `href` / `mailto:` и в видимом тексте.

```html
<h3 class="contact__name">Имя Фамилия</h3>
<a class="contact__link" href="https://github.com/login1">github.com/login1</a>
<a class="contact__link" href="mailto:name1@example.com">name1@example.com</a>
```

### 4. По желанию: свои стили или скрипт

**CSS** — добавляйте в **конец** `styles.css`, со своими новыми классами (например `.ivan-gallery`). Существующие правила не меняйте: они общие для всех страниц. Цвета берите из переменных, тогда тёмная тема заработает сама:

```css
.ivan-gallery {
  border: 1px solid var(--color-text);
  color: var(--color-text-muted);
}
```

**JS** — добавляйте в **конец** `app.js`. Он подключён на всех страницах, поэтому свой код оборачивайте в проверку, иначе на чужих страницах будет ошибка:

```js
const ivanButton = document.querySelector("#ivan-button");

if (ivanButton) {
  ivanButton.addEventListener("click", () => {
    // что делает кнопка
  });
}
```

`id` придумывайте со своим именем (`ivan-button`), чтобы не совпасть с чужими.

## Как вносить изменения

**На сайте GitHub:**

- файл: открыть → ✏️ → поправить → **Commit changes**;
- картинка: открыть папку `images` → **Add file → Upload files**.

**Через git:**

```bash
git clone https://github.com/KirillKrainov22/WEB--1.git
cd WEB--1
git pull                          # перед началом работы — забрать изменения других
git add .
git commit -m "Заполнил свою страницу"
git push
```

Сайт обновляется через 1–2 минуты после изменений. Ход сборки — во вкладке **Actions**: зелёная галочка значит, что сайт обновлён.
