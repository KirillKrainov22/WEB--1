# Любовь Чибакова | Мои проекты

При открытии страницы раздел «Мои проекты» загружает до 100 публичных репозиториев LuCh-Ans, начиная с недавно обновлённых. В карточке есть название со ссылкой, описание и основной язык. Кнопка «Обновить» запрашивает список заново. [Запрос к GitHub API](https://api.github.com/users/LuCh-Ans/repos?sort=updated&per_page=100)

## Локальный запуск

Для работы нужны Node.js (например, 22.12 или новее в ветке 22) и npm. Из корня репозитория перейдите в папку страницы и запустите Vite.

```sh
cd members/lyuba
npm install
npm run dev
```

Откройте адрес из терминала. Чтобы проверить версию для публикации, остановите сервер сочетанием Ctrl+C и выполните в той же папке:

```sh
npm run build
npm run preview
```

Сборка появится в dist/. Ссылка «На главную» рассчитана на размещение страницы внутри общего сайта команды.

## Проверено

- Страница из сборки загружает реальные репозитории LuCh-Ans. Ссылки ведут на GitHub.
- Во время запроса отображается «Загрузка…», кнопка временно отключена. Обновление очищает предыдущие карточки.
- Для пустого ответа отображается «Ничего не найдено». При ошибке HTTP или обрыве сети появляется кнопка «Повторить». После успешной попытки карточки возвращаются.
- При отсутствии описания или языка выводятся подписи-заглушки. Переключение темы и кнопка «Подробнее» работают, изображения включены в сборку.
- При ширине окна 320, 390 и 1280 пикселей страница помещается по ширине без горизонтальной прокрутки.
