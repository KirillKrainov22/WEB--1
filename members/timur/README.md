# Лабораторные работы 1 и 2 — Тимур Кутуев

В первой работе я сделал личную страницу с переключением темы, блоком об LGG School и фильтром подборки музыки, кино и игр. Во второй работе подключил Vite, перенёс копии картинок, текстуры и шрифтов в папку страницы и добавил раздел «Мои проекты».

Раздел запрашивает [публичные репозитории KutuevTimur через GitHub API](https://api.github.com/users/KutuevTimur/repos?sort=updated&per_page=100) при открытии страницы и по кнопке «Обновить». Карточки показывают название со ссылкой на GitHub, описание и язык. Для публичного запроса токен не нужен.

## Локальный запуск

Из корня командного репозитория перейдите в `members/timur/`. Все команды npm выполняются из этой папки.

```sh
cd members/timur
npm install
npm run dev
```

Откройте адрес, который выведет Vite. Для проверки готовой сборки остановите сервер разработки сочетанием Ctrl+C и выполните:

```sh
npm run build
npm run preview
```

## Что проверено

- Публичный API вернул репозитории аккаунта KutuevTimur.
- В Chrome на серверах разработки и предпросмотра с тестовыми ответами проверены загрузка, блокировка кнопки на время запроса, обновление, карточка без описания и языка, пустой список, сетевая ошибка, ответ HTTP 403 и успешный повтор.
- Проверены изображения, шрифты, переключение темы, раскрытие подробностей об LGG и фильтр. На ширине 320 и 1280 пикселей проверено отсутствие горизонтальной прокрутки, в том числе с длинным названием проекта.
- После публикации ссылка «На главную» проверяется на [сайте команды](https://kirillkrainov22.github.io/WEB--1/members/timur/).


## Лабораторная работа 3 — React и TypeScript

Страница перенесена на React с TypeScript. Содержание, фотографии и оформление сохранены.

- `App.tsx` собирает страницу и хранит состояние ночного режима; выбор сохраняется в localStorage.
- `Header` содержит навигацию и переключатель темы, `Profile` — биографию и раскрываемый текст об LGG, `Sports` — рассказ о спорте, `Favorites` — подборку с фильтром музыки, кино и игр, `Footer` — контакты и подвал.
- `Projects` загружает репозитории через GitHub API при открытии и по кнопке обновления. Компонент показывает загрузку, пустой список, ошибку и повторную попытку. При очистке эффекта запрос отменяется через AbortController; отмена не показывается как ошибка.
- `ProjectCard` получает типизированный репозиторий через props. Поля данных описаны в `src/types.ts`, запрос и проверка ответа находятся в `src/api/github.ts`. Учтены пустые описание и язык.
- У каждого блока свой `.module.css`; общие классы страницы находятся в `App.module.css`, шрифты, сброс, переменные и тема — в `global.css`. Картинки, текстура и шрифты находятся в `src/assets` и включаются Vite в сборку.
- Старые скрипты и стили удалены из личной папки. Интерфейс и обработчики работают через React, без ручного создания карточек в DOM.

Команды запуска остались прежними: `npm install`, `npm run dev`, `npm run build`, `npm run preview`. Сборка сначала проверяет типы командой `tsc --noEmit`, затем создаёт `dist/`.
