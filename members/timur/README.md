# Лабораторные работы 1 и 2 — Тимур Кутуев

В первой работе я сделал личную страницу с переключением темы, блоком об LGG School и фильтром подборки музыки, кино и игр. Во второй работе подключил Vite, перенёс копии картинок, текстуры и шрифтов в папку страницы и добавил раздел «Мои проекты».

Раздел запрашивает [публичные репозитории KutuevTimur через GitHub API](https://api.github.com/users/KutuevTimur/repos?sort=updated&per_page=100) при открытии страницы и по кнопке «Обновить». Карточки показывают название со ссылкой на GitHub, описание и язык. Для публичного запроса токен не нужен.

## Локальный запуск

Из корня командного репозитория перейдите в `members/timur/`. Все команды npm выполняются из этой папки.

```sh
cd members/timur
npm install
npm run dev
```

Откройте адрес, который выведет Vite. Для проверки готовой сборки остановите сервер разработки сочетанием Ctrl+C и выполните:

```sh
npm run build
npm run preview
```

## Что проверено

- Публичный API вернул репозитории аккаунта KutuevTimur.
- В Chrome на серверах разработки и предпросмотра с тестовыми ответами проверены загрузка, блокировка кнопки на время запроса, обновление, карточка без описания и языка, пустой список, сетевая ошибка, ответ HTTP 403 и успешный повтор.
- Проверены изображения, шрифты, переключение темы, раскрытие подробностей об LGG и фильтр. На ширине 320 и 1280 пикселей проверено отсутствие горизонтальной прокрутки, в том числе с длинным названием проекта.
- После публикации ссылка «На главную» проверяется на [сайте команды](https://kirillkrainov22.github.io/WEB--1/members/timur/).
