# Кирилл Крайнов — лабораторные работы 1 и 2

Личная страница на общем сайте команды, созданная в рамках курса по веб-программированию.

[Открыть страницу](https://kirillkrainov22.github.io/WEB--1/members/kirill/)

## Лабораторная работа №1

Создана личная страница на HTML, CSS и JavaScript.

На странице размещены:

- фотография и информация обо мне;
- увлечения и любимые фильм, спорт и музыка;
- ссылки на GitHub и Telegram.

Добавлены кнопка «Подробнее», которая раскрывает дополнительный текст, и переключатель светлой и тёмной темы. Выбранная тема сохраняется при перезагрузке страницы.

## Лабораторная работа №2

Страница переведена на Vite с использованием обычного JavaScript — Vanilla + JavaScript.

Добавлен раздел **«Мои проекты»**, который получает данные из GitHub API через `fetch` и показывает публичные репозитории моего аккаунта.

В каждой карточке отображаются:

- название со ссылкой на репозиторий;
- описание;
- основной язык программирования;
- количество звёзд;
- дата обновления.

Если описание или язык отсутствуют, выводится соответствующая подпись.

### Поиск и обновление

Поиск работает по названию и описанию проекта без учёта регистра. Фильтрация выполняется по уже загруженным данным, поэтому при вводе текста дополнительные запросы к API не отправляются.

Кнопка **«Обновить»** повторно загружает список с GitHub.

### Состояния приложения

- Во время запроса отображается **«Загрузка…»**.
- После успешной загрузки появляются карточки и количество проектов.
- При пустом ответе или отсутствии совпадений в поиске выводится **«Ничего не найдено»**.
- При ошибке отображаются понятное сообщение и кнопка **«Повторить»**.

Перед обработкой ответа проверяется `response.ok`. Обрабатываются ошибки HTTP, отсутствие соединения и превышение времени ожидания запроса.

### Оформление

Новый раздел оформлен в стиле существующей страницы. Он поддерживает светлую и тёмную темы и адаптируется к узкому экрану.

Изображения, стили и скрипты страницы размещены внутри папки участника, чтобы проект можно было запускать и собирать отдельно.

## Используемый API

[GitHub REST API — репозитории пользователя](https://docs.github.com/en/rest/repos/repos#list-repositories-for-a-user)

```text
GET https://api.github.com/users/KirillKrainov22/repos?sort=updated&per_page=100
```

Запрос возвращает до 100 последних обновлённых публичных репозиториев. Авторизация и секретный ключ не требуются.

Без авторизации действует ограничение GitHub: 60 запросов в час с одного IP.

## Запуск

Нужен Node.js совместимой с Vite версии, например 22.12 или новее в ветке 22.

Из корня репозитория:

```bash
cd members/kirill
npm ci
npm run dev
```

После запуска нужно открыть адрес, указанный в терминале.

## Сборка

Из папки `members/kirill/`:

```bash
npm run build
```

Готовые файлы создаются в папке `dist/`. Для просмотра сборки:

```bash
npm run preview
```

Папки `node_modules/` и `dist/` исключены через `.gitignore`.

Общая публикация настроена через GitHub Actions: после отправки изменений в `main` страница собирается и публикуется на GitHub Pages.

## Что проверено

- Установка зависимостей через `npm ci` и успешная сборка.
- Загрузка реальных репозиториев через GitHub API в браузере.
